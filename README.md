# CodeAlpha - Basic Network Sniffer

A simple Python-based network sniffer built using `scapy` to capture and analyze network packets in real-time. This project extracts key packet information including source IP addresses, destination IP addresses, and underlying protocols.

---

## Features

- Captures live network traffic.
- Parses IP headers to display Source IP, Destination IP, and Protocol IDs.
- Lightweight and easy to run on Windows, macOS, or Linux.
